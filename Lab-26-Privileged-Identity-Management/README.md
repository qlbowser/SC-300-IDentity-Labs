# Lab 26 – Privileged Identity Management (PIM)

## Objective
Configure Microsoft Entra Privileged Identity Management (PIM) to provide just-in-time privileged access while reducing standing administrative privileges.

## What I Configured
- Configured approval requirements for the Compliance Administrator role
- Assigned an eligible privileged role using PIM
- Requested just-in-time role activation
- Approved the privileged access request
- Verified the activated role
- Removed the privileged role assignment after testing

## Key Skills
Microsoft Entra ID • Privileged Identity Management (PIM) • Just-in-Time Access • Role-Based Access Control (RBAC) • Least Privilege • Privileged Access Governance
